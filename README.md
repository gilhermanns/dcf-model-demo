# DCF Model Demo

[![GitHub Stars](https://img.shields.io/github/stars/gilhermanns/dcf-model-demo?style=social)](https://github.com/gilhermanns/dcf-model-demo/stargazers)

This repository showcases the outputs generated by the `modern-automated-dcf` tool. It demonstrates how the model processes financial data and produces valuation summaries.

## Sample Outputs

The model generates comprehensive Excel reports including:
*   10-year explicit forecast + perpetuity
*   WACC calculation from market data
*   Sensitivity analysis for various growth and discount rate scenarios
*   Enterprise and Equity value breakdown

## Quick Run

To reproduce these results, first install the `modern-automated-dcf` tool:

```bash
git clone https://github.com/gilhermanns/modern-automated-dcf.git
cd modern-automated-dcf
pip install -r requirements.txt
```

Then, run the demo script:

```bash
python run_demo.py --tickers AAPL,MSFT
```

## DCF Methodology

The Discounted Cash Flow (DCF) model estimates the intrinsic value of an asset based on its expected future cash flows. The core steps involve:

1.  **Forecasting Free Cash Flow (FCF)**: Projecting the cash generated by the company after accounting for capital expenditures.
2.  **Calculating Weighted Average Cost of Capital (WACC)**: Determining the average rate of return a company expects to pay to finance its assets.
3.  **Estimating Terminal Value (TV)**: Calculating the value of the company's cash flows beyond the explicit forecast period.
4.  **Discounting Future Cash Flows**: Summing the present values of the projected FCFs and the Terminal Value to arrive at the Enterprise Value.
5.  **Calculating Equity Value**: Adjusting the Enterprise Value by adding cash and subtracting debt to get the Equity Value.
6.  **Determining Intrinsic Value Per Share**: Dividing the Equity Value by the number of outstanding shares.
